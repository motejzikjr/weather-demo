# Geolocation

## Cíl

Rozšíření aplikace o možnost zadat konkrétní místo pro zobrazení počasí. Stávající hardcoded tlačítka s městy se odeberou a nahradí autocomplete našeptávačem napojeným na Open-Meteo Geocoding API. Vybrané místo se uloží do Pinia store a aplikace načte počasí pro jeho koordináty.
