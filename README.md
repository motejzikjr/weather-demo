# Weather Demo aplikace

## Prerekvizity
- Node.js >= 22.0.0

## Instalace
- npm install

## Veřejná URL
- https://motejzikjr.github.io/weather-demo/

  ## Scripty
- `npm run dev` — vývojový server
- `npm run build` — typecheck + produkční build
- `npm run preview` — náhled produkčního buildu
- `npm run typecheck` — kontrola TypeScript
- `npm run lint` — ESLint kontrola
- `npm run lint:fix` — ESLint s automatickými opravami
- `npm run format` — Prettier formátování

## Technologie
- Vue 3 composition API
- TypeScript
- Vite
- Tailwind CSS
- Less
